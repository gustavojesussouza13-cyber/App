# Gustavo, O Peregrino — APK de testes

Este repositório serve para compilar o projeto Android **Gustavo, O Peregrino** e gerar um APK de testes pelo GitHub Actions.

## Como gerar o APK
1. Envie o arquivo `Gustavo_O_Peregrino_Projeto_Android_PlayStore.zip` para a raiz deste repositório pelo botão **Add file → Upload files → Commit changes**.
2. Abra a aba **Actions**, selecione **Gerar APK - Gustavo O Peregrino** e aguarde o resultado da execução iniciada pelo upload.
3. Abra a execução concluída e, em **Artifacts**, baixe **Gustavo-O-Peregrino-APK**.
4. Extraia o ZIP baixado e instale `app-debug.apk` no seu Android. Habilite instalação dessa fonte apenas se o Android solicitar.

O aplicativo funciona offline, salvando dados no próprio aparelho. O arquivo APK de teste não é a versão definitiva a ser enviada à Google Play.
